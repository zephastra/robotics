# 04 工作空间与包：组织并编译 ROS 2 代码

> 状态：Source Reviewed
> 适用环境：ROS 2 Lyrical
> 最后核对：2026-08-31
> 原文：[Creating a workspace](https://docs.ros.org/en/lyrical/Tutorials/Beginner-Client-Libraries/Creating-A-Workspace/Creating-A-Workspace.html)、[Creating a package](https://docs.ros.org/en/lyrical/Tutorials/Beginner-Client-Libraries/Creating-Your-First-ROS2-Package.html)
> 上游许可：[CC BY 4.0](https://github.com/ros2/ros2_documentation/blob/lyrical/LICENSE)

Workspace（工作空间）包含一个或多个 ROS 2 包。Package（包）是 ROS 2 代码构建、安装和分发的基本单位。

## 1. 典型结构

```text
ros2_ws/
├── src/       # 源码
├── build/     # 构建中间文件
├── install/   # 安装结果与环境脚本
└── log/       # 构建日志
```

`build`、`install` 和 `log` 由 `colcon` 生成，不应提交到 Git。

## 2. 创建工作空间

```bash
source /opt/ros/lyrical/setup.bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
colcon build
source install/setup.bash
```

首次构建一个空工作空间也是合法的。

## 3. 创建 Python 包

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_python \
  --license Apache-2.0 \
  my_py_pkg \
  --dependencies rclpy std_msgs
```

## 4. 创建 C++ 包

```bash
cd ~/ros2_ws/src
ros2 pkg create --build-type ament_cmake \
  --license Apache-2.0 \
  my_cpp_pkg \
  --dependencies rclcpp std_msgs
```

`Apache-2.0` 只是示例。创建真实项目时，应根据项目需求主动选择许可证，不要保留未确认的占位许可。

## 5. 选择性编译

```bash
cd ~/ros2_ws
colcon build --packages-select my_py_pkg
source install/setup.bash
```

开发 Python 包时可以使用符号链接安装：

```bash
colcon build --symlink-install --packages-select my_py_pkg
```

## 6. Overlay 注意事项

每个新终端都应先加载基础 ROS 环境，再加载工作空间：

```bash
source /opt/ros/lyrical/setup.bash
source ~/ros2_ws/install/setup.bash
```

不要在同一个终端里构建工作空间的同时，加载该工作空间旧的 overlay；遇到异常时可打开一个新终端重新构建。
