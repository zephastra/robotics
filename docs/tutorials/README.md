# Tutorials

`tutorials/` 存放 Zephastra 编写和维护的正式教程集合。

“教程”表示内容以清晰的学习目标和可执行步骤组织，并不代表所有章节都已经完成端到端验证。每篇教程必须标注以下状态之一：

| 状态 | 含义 |
| --- | --- |
| Verified | 已在标注环境中完整复现 |
| Environment Verified | 已确认环境或软件包，尚未验证全部步骤 |
| Source Reviewed | 已与上游资料核对，尚未完整复现 |
| Draft | 仍有占位符、依赖或端到端验证工作 |
