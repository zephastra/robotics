# 05 发布订阅实战：Python Publisher 与 Subscriber

> 状态：Source Reviewed
> 适用环境：ROS 2 Lyrical、Python 3
> 最后核对：2026-08-31
> 原文：[Writing a simple publisher and subscriber (Python)](https://docs.ros.org/en/lyrical/Tutorials/Beginner-Client-Libraries/Writing-A-Simple-Py-Publisher-And-Subscriber.html)
> 上游许可：[CC BY 4.0](https://github.com/ros2/ros2_documentation/blob/lyrical/LICENSE)

本篇创建一个每 0.5 秒发布字符串的节点，以及一个接收并打印字符串的节点。

## 1. 创建包

```bash
source /opt/ros/lyrical/setup.bash
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src

ros2 pkg create --build-type ament_python \
  --license Apache-2.0 \
  py_pubsub \
  --dependencies rclpy std_msgs
```

## 2. 编写发布者

新建 `~/ros2_ws/src/py_pubsub/py_pubsub/publisher_member_function.py`：

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class MinimalPublisher(Node):

    def __init__(self):
        super().__init__('minimal_publisher')
        self.publisher_ = self.create_publisher(String, 'topic', 10)
        self.timer = self.create_timer(0.5, self.timer_callback)
        self.i = 0

    def timer_callback(self):
        msg = String()
        msg.data = f'Hello World: {self.i}'
        self.publisher_.publish(msg)
        self.get_logger().info(f'Publishing: "{msg.data}"')
        self.i += 1


def main(args=None):
    rclpy.init(args=args)
    node = MinimalPublisher()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

队列深度 `10` 是本示例使用的 QoS 参数，并不代表所有项目都应固定使用该值。

## 3. 编写订阅者

新建 `~/ros2_ws/src/py_pubsub/py_pubsub/subscriber_member_function.py`：

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


class MinimalSubscriber(Node):

    def __init__(self):
        super().__init__('minimal_subscriber')
        self.subscription = self.create_subscription(
            String,
            'topic',
            self.listener_callback,
            10,
        )

    def listener_callback(self, msg):
        self.get_logger().info(f'I heard: "{msg.data}"')


def main(args=None):
    rclpy.init(args=args)
    node = MinimalSubscriber()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()


if __name__ == '__main__':
    main()
```

## 4. 配置入口点

编辑 `~/ros2_ws/src/py_pubsub/setup.py`，确认 `entry_points` 包含：

```python
entry_points={
    'console_scripts': [
        'talker = py_pubsub.publisher_member_function:main',
        'listener = py_pubsub.subscriber_member_function:main',
    ],
},
```

## 5. 构建和运行

```bash
cd ~/ros2_ws
rosdep install -i --from-path src --rosdistro lyrical -y
colcon build --packages-select py_pubsub
```

终端 1：

```bash
source /opt/ros/lyrical/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 run py_pubsub talker
```

终端 2：

```bash
source /opt/ros/lyrical/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 run py_pubsub listener
```

订阅者持续显示 `I heard: "Hello World: ..."` 即完成验证。

## 6. 常见问题

- 找不到可执行文件：检查 `setup.py` 的入口点并重新构建。
- 找不到包：确认加载了 `~/ros2_ws/install/setup.bash`。
- 修改代码不生效：重新构建；也可在开发阶段使用 `--symlink-install`。
