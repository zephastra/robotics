# 02 节点与话题：理解 ROS 图

> 状态：Source Reviewed
> 适用环境：ROS 2 Lyrical
> 最后核对：2026-08-31
> 原文：[Understanding nodes](https://docs.ros.org/en/lyrical/Tutorials/Beginner-CLI-Tools/Understanding-ROS2-Nodes/Understanding-ROS2-Nodes.html)、[Understanding topics](https://docs.ros.org/en/lyrical/Tutorials/Beginner-CLI-Tools/Understanding-ROS2-Topics/Understanding-ROS2-Topics.html)
> 上游许可：[CC BY 4.0](https://github.com/ros2/ros2_documentation/blob/lyrical/LICENSE)

Node（节点）是 ROS 2 计算图中的参与者，Topic（话题）是发布者和订阅者传递消息的命名通道。

## 1. ROS 图

```text
[雷达节点] -- /scan --> [建图节点] -- /map --> [导航节点]
                                              |
                                              +-- /cmd_vel --> [底盘节点]
```

- 一个节点通常负责一项相对独立的功能。
- 一个进程可以包含一个或多个节点；“一个程序等于一个节点”并不是 ROS 2 的硬性规则。
- 同一话题可以有多个发布者和多个订阅者。
- 发布者与订阅者通过消息类型和 QoS 匹配，不需要直接知道彼此的实现。

## 2. 启动 turtlesim

终端 1：

```bash
source /opt/ros/lyrical/setup.bash
ros2 run turtlesim turtlesim_node
```

终端 2：

```bash
source /opt/ros/lyrical/setup.bash
ros2 run turtlesim turtle_teleop_key
```

保持终端 2 获得键盘焦点，用方向键控制海龟。

## 3. 检查节点

```bash
ros2 node list
ros2 node info /turtlesim
```

典型节点包括：

```text
/turtlesim
/teleop_turtle
```

## 4. 检查话题

```bash
ros2 topic list
ros2 topic list -t
ros2 topic info /turtle1/cmd_vel
ros2 topic echo /turtle1/cmd_vel
```

在键盘控制终端按方向键时，`ros2 topic echo` 应显示 `geometry_msgs/msg/Twist` 消息。

## 5. 手动发布消息

先停止键盘控制节点，或确保它没有持续发布速度命令。然后运行：

```bash
ros2 topic pub --once /turtle1/cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 2.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 1.8}}"
```

查看消息结构：

```bash
ros2 interface show geometry_msgs/msg/Twist
```

## 6. 用 rqt_graph 查看连接关系

```bash
ros2 run rqt_graph rqt_graph
```

若命令不可用，先确认 `rqt_graph` 包已安装。

## 7. 常见问题

- YAML 参数报错：检查冒号后的空格、引号和花括号。
- 话题存在但收不到数据：先核对话题名、消息类型、发布者数量，再检查 QoS 是否兼容。
- 看不到节点：确认各终端都加载了相同的 ROS 环境，并检查 `ROS_DOMAIN_ID` 是否一致。
