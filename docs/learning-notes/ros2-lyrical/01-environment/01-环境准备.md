# 01 环境准备：Ubuntu 26.04 + ROS 2 Lyrical

> 状态：Environment Verified
> 适用环境：Ubuntu 26.04 LTS、ROS 2 Lyrical Luth
> 最后核对：2026-08-31
> 原文：[ROS 2 Lyrical Ubuntu 安装说明](https://docs.ros.org/en/lyrical/Installation/Ubuntu-Install-Debs.html)
> 上游许可：[CC BY 4.0](https://github.com/ros2/ros2_documentation/blob/lyrical/LICENSE)

本篇说明如何通过 Debian 软件包安装 ROS 2 Lyrical，并用官方 `talker` / `listener` 示例确认基础通信可用。本文是中文学习笔记，不是官方逐字译文。

## 1. 环境基线

| 项目 | 本文基线 |
| --- | --- |
| 操作系统 | Ubuntu 26.04 LTS（Resolute Raccoon） |
| ROS 2 | Lyrical Luth |
| 安装包 | `ros-lyrical-desktop` |
| ROS 安装路径 | `/opt/ros/lyrical` |
| 当前审计环境 Python | 3.14.4 |

ROS 2 Lyrical 支持 Ubuntu 26.04。其他 Ubuntu 或 ROS 2 版本不能直接照抄本文的软件包名。

## 2. 安装步骤

### 2.1 设置 UTF-8 locale

```bash
sudo apt update
sudo apt install locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8
locale
```

### 2.2 启用 Universe 仓库

```bash
sudo apt install software-properties-common
sudo add-apt-repository universe
```

### 2.3 安装 ROS APT 源配置包

官方目前推荐用 `ros2-apt-source` 软件包配置仓库。下面的命令会从 GitHub 获取最新发布版本；执行前应检查变量是否成功取得版本号。

```bash
sudo apt update
sudo apt install curl -y

export ROS_APT_SOURCE_VERSION=$(curl -s \
  https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest \
  | grep -F "tag_name" | awk -F '"' '{print $4}')

echo "$ROS_APT_SOURCE_VERSION"

curl -L -o /tmp/ros2-apt-source.deb \
  "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.$(. /etc/os-release && echo ${UBUNTU_CODENAME:-${VERSION_CODENAME}})_all.deb"

sudo dpkg -i /tmp/ros2-apt-source.deb
```

若上述命令与官方安装页不同，应以官方页面为准。

### 2.4 安装开发工具和 ROS 2 Desktop

```bash
sudo apt update
sudo apt install ros-dev-tools
sudo apt upgrade
sudo apt install ros-lyrical-desktop
```

`ros-lyrical-desktop` 包含 RViz 和常用示例。只需要核心通信组件时，可安装 `ros-lyrical-ros-base`。

### 2.5 加载环境

```bash
source /opt/ros/lyrical/setup.bash
printenv ROS_DISTRO
```

预期输出：

```text
lyrical
```

## 3. 验证安装

打开两个终端。

终端 1：

```bash
source /opt/ros/lyrical/setup.bash
ros2 run demo_nodes_cpp talker
```

终端 2：

```bash
source /opt/ros/lyrical/setup.bash
ros2 run demo_nodes_py listener
```

若 `talker` 持续发布消息，`listener` 持续接收消息，说明 ROS 2 的基本环境和节点通信工作正常。按 `Ctrl+C` 停止进程。

## 4. WSL 说明

- 建议把 ROS 工作空间放在 WSL 的 Linux 文件系统中，例如 `~/ros2_ws`。
- `/mnt/c` 适合交换文件，但在其中进行大量编译通常较慢，还可能遇到权限和文件监听差异。
- 图形界面能否显示取决于 WSLg 或其他图形转发配置；`talker` / `listener` 验证本身不需要 GUI。

若希望每次打开 Bash 自动加载 ROS 2，可执行：

```bash
echo 'source /opt/ros/lyrical/setup.bash' >> ~/.bashrc
source ~/.bashrc
```

追加前可先检查 `~/.bashrc`，避免重复写入同一行。

## 5. 快速检查

```bash
printenv ROS_DISTRO
which ros2
ros2 pkg prefix demo_nodes_cpp
python3 --version
```
