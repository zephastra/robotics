## Selection notes

- 初学者可从 **Modern Robotics** 开始，再根据项目需要学习控制、规划或状态估计。
- **Underactuated Robotics** 和 **Probabilistic Robotics** 数学要求较高，不建议把它们当作第一次接触机器人的入门资料。
- 图书主页只证明出版来源，不等于图书正文可以免费复制或再发布。
