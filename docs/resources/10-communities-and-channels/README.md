## Review policy for channels

- `Source Checked`：只确认频道、作者和链接属于所列来源。
- `Pending`：已发现但尚未完成作者、范围或版本核对。
- 只有完整看过、实际跟做并检查版本问题后，才升级为 `Reviewed` 或 `Recommended`。
- 搬运、无来源重传、夸张标题但无项目资料的合集不收录。

新增资源时使用 [统一模板](../RESOURCE_TEMPLATE.md)。
