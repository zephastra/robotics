# Resource Entry Template

复制下面的模板，将占位内容替换为真实信息。一个页面可以包含多个条目。

```markdown
## Resource title

- URL: <https://example.com>
- Author / Organization: Name
- Platform: Official Docs / YouTube / Bilibili / Book / Blog / Course
- Resource type: Documentation / Tutorial / Course / Video / Tool / Community
- Language: Chinese / English / Other
- Topic: ROS 2 / SLAM / Control / Perception / ...
- Level: Beginner / Intermediate / Advanced
- Version or date: ROS 2 Lyrical / Not specified / 2026
- Cost: Free / Paid / Mixed
- Review status: Pending / Source Checked / Reviewed / Recommended / Archived
- Last checked: YYYY-MM-DD

### Summary

用自己的语言概括这项资源解决什么问题、覆盖哪些内容。

### Why it may be useful

说明适合哪些读者，以及它与同类资源相比有什么特点。

### Caveats

记录版本过旧、环境差异、内容缺失、付费限制或其他注意事项。
```

## Minimum requirements

至少必须填写：URL、作者或机构、平台、主题、版本、评审状态和最后检查日期。
