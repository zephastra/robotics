## Reading rules for fast-moving AI material

- 先看原项目的文档、代码仓库、模型卡和数据集卡，再看二次解读。
- 记录论文日期、代码 commit、数据版本、训练硬件和评测协议；只记录模型名称不足以复现结果。
- 演示视频不能替代成功率、失败案例、基线和真实机器人评测。
- `Source Checked` 只表示来源已经确认，不代表已经复现实验或认可论文结论。
