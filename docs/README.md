# Documentation

`docs/` 存放跨项目文档、学习笔记、架构说明和参考资料。可运行代码应放在 `projects/`，项目专用文档应放在对应项目内部。

## Learning notes

- [ROS 2 Lyrical 中文学习笔记](learning-notes/ros2-lyrical/README.md)

## Publication rules

1. 每篇资料注明适用版本、来源、许可和最后核对日期。
2. 区分 Verified、Source Reviewed、Draft 和 Project Note。
3. AI 辅助翻译必须经过来源和技术审计，不能标为官方翻译。
4. 第三方代码、图片和文档保留原许可证与署名。
5. 命令只有在指定环境实际复现后，才能标记为 Verified。

原创文档内容的许可见 [LICENSE.md](LICENSE.md)。
