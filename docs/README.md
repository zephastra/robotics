## Publication rules

1. 每篇资料注明适用版本、来源、许可和最后核对日期。
2. 区分 Verified、Source Reviewed、Draft 和 Project Note。
3. AI 辅助翻译必须经过来源和技术审计，并明确标为非官方教程。
4. 第三方代码、图片和文档保留原许可证与署名。
5. 命令只有在指定环境实际复现后，才能标记为 Verified。
