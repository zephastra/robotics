## 30 组固定测试

```bash
cd ~/projects/007_humanoid_visual_transport
.venv/bin/python -m pytest -q
.venv/bin/python scripts/batch.py --list
.venv/bin/python scripts/batch.py --seed 7 --workers 2
```

- 3 组：第一版已有的默认、正偏移、负偏移回归。
- 9 组：箱体 X ∈ {-20, 0, 20} mm，Y ∈ {-10, 0, 10} mm；目标不动。
- 9 组：目标 X ∈ {-50, 0, 50} mm，Y ∈ {-30, 0, 30} mm；箱体不动。
- 9 组：固定随机种子，组合上述偏移范围和 ±5° 箱体偏航。

这些是**启动前的场景变化**，不是抓取途中移动物体。部分基础场景重复，用于分组回归；
不能把 30 次结果当作独立同分布的真实部署成功率。

每组有自己的日志和原始报告副本。批次目录为 `reports/batch-<UTC时间>/`，
`summary.json` 逐例更新，保存全部参数、源码/资源 SHA256、返回码、结果和评估指标。
每组墙钟超时默认 300 秒，只终止该测试自己的进程组。失败不会自动重跑后覆盖。
每次运行创建新批次，不会悄悄跳过旧失败。批次结束检查输入文件未变化。

修复后可指定原始编号另建批次重跑，例如：

```bash
.venv/bin/python scripts/batch.py --seed 7 --case 22-combined-yaw 23-combined-yaw
```

只重跑失败样例不等于完整回归；控制逻辑修改后仍需要重新跑全部 30 组。
