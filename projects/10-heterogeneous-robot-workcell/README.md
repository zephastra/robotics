目标：在一个共同物理世界中，1 台人形机器人、1 台固定机械臂、2 台 AMR，以及固定/车载输送机构协作完成一张备料配送订单。
不含加工机床、复杂装配、真实硬件和工业安全认证。

## 首版故事

1. 人形机器人从腰部高度的托盘架取一个轻量空托盘，放到已停止的输送带上料工位。
2. 人形退出操作区，固定机械臂从分开放置的零件中选取指定种类和数量，装入托盘。
3. 相机核对配料；机械臂退出，输送带把订单托盘送到接驳位。
4. 调度器分配一台空闲 AMR；小车导航、停靠，经互锁确认后由固定与车载输送机构完成真实托盘转移。
5. AMR 运输到配送工位，与固定接收输送台对接卸盘。
6. 物品种类、数量、托盘位置及任务归属经独立验收后，订单才能完成。

双车任务必须在额外场景验证通道/站点竞争。首个单车成功不能代表多机器人首版完成。
