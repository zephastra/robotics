## 修订 1（2026-10-04，首次运行失败后、复跑前追记）

**首跑 `p4-belt-g4-armv7-01` FAILED（3.6 s，证据保留于 `reports/p4-belt-g4-armv7-01/`，run id 不复用）。**
失败点：开门 IK（approach，半径 0.61 m）不收敛，best pos 0.55288 m。

**根因（A/B 实测，非猜测）**：v1 探针的 `data` 从未用家态键帧初始化，臂 qpos = 原始零位，
所有 IK 都以零位为种子 ⇒ DLS 陷阱：同一目标、同一求解器，零位种子卡在 0.55288 m，
家态键帧种子 `[0, 0, 0, −1.5708, 0, 1.5708, −0.7853]` 收敛到 3e-5 m。
**是求解器陷阱，不是可达性边界**（桌面扫掠 50/50 点收敛的事实不变）。

**探针修订（仍只动新探针文件，零现有代码/世界改动）**：
1. `data` 以 `mj_resetDataKeyframe(0) + mj_forward` 初始化（世界的声明初始条件）；
2. **声明并计数的初始化 ctrl 写**：臂伺服保持家态位、夹爪开（因为 home 键帧的 `key_ctrl`
   把臂伺服命令为 0，放着不管臂会塌——v7 世界缺陷，如实报 finding；修世界属另一次声明，本次不做）；
3. 每次 IK 以臂当前状态为种子；
4. 释放稳定性 qvel 切片改用 `jnt_dofadr`（推送前自查抓出的 qpos/dof 地址混用）。
