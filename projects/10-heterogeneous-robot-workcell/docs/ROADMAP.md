# 首版与扩展路线

本文是范围规划，不代表功能已实现。当前状态以 IMPLEMENTATION_STATUS 为准。

## V1：有限订单、真实交接

固定房间、腰高托盘架、分开放置的两类零件、停带抓放、两台 AMR、一处收货站。
人形负责空托盘供给，机械臂负责配料，输送设备负责交接，小车负责运输。
订单为结构化输入；至少验证两订单竞争。机器人不能靠运行时传送物体完成任务。
SLAM 用于建图，配送用已有地图定位；PCL/点云用于桌面与简单零件定位。
这是完整的协同系统，但不是泛化机器人、无限生产或工业安全认证。

### 为什么先让人形拿空盘

先把人形动作限制在轻负载、可达的腰高区域；不把 007/008 尚不稳定的侧向满载放置作为关键路径。
人形仍须自由底座、真实接触、抓住并放下托盘；不能退化成一个外观模型。
首版是否能用现有手部/控制器实现，必须由 P1 验证，不预先宣称稳定。

## V1.1：循环运行与恢复

前置：V1 冻结验收完成。每次只选一个扩展。

- 增加空盘回收线路，明确空盘与订单托盘不同生命周期。
- 库存数量、料位占用、补料任务；不自动生成货物来补库存。
- 电量下降时在安全交接点换车；持货车辆不能直接把任务标签转给另一辆车。
- 在 V1 重启后禁止错误派单和保留归属的基础上，增加自动对账恢复与孤儿任务处理；重启不等于恢复授权。
- 运行数个有限生产循环，报告吞吐、失败分类、人工介入次数，而不是只展示最快一次。

## V2：变化环境与视觉闭环

前置：单独冻结一个扰动范围，不同时增加新机器人和新感知算法。

- 从 V1 开始前的小范围位置变化，扩展到任务进行中的料件移动；持续观察、定位、抓取前复核。
- 输送托盘偏移后重新测量对接；遮挡或证据过期时停止并重新观察。
- 接收站占用时排队或选择经过验证的备用站，不凭语言推测可达。
- 人形增加短距取盘、注视动作与有界站位修正；满载双手行走作为独立实验。
- 可选移动带抓取：需轨迹预测、时间标定和追踪验收，不能视为改一个带速参数。

## V3：任务交互与平台扩展

- 接入 008 的思路：语言转结构化订单，校验数量、物料与目的地，信息不足追问。
- LLM 只能提案，不能绕过执行监督；先回放/影子模式，再有限授权。
- 增加第三辆车、第二机械臂或第二工位，重新验证资源图、交通死锁与容量。
- 硬件接口适配：优先单个低成本台架/输送模块或小车，不直接购买整个人形系统。
- 真机需要独立风险评估、急停、电气与机械保护；仿真 PASS 不等于可直接运行真机。

## 扩展立项模板

每项写清：用户场景、与 V1 的差异、复用模块、新物理假设、测试用例、退出门、回退方式。
必须保留 V1 配置和基线。扩展失败不能破坏已经交付的 V1。
不把 V1.1/V2/V3 加入 V1 必达条件；V1 完成后可以停止，后续按用途选择。
