# 分步开发指南（交给实施 AI）

只描述将来工作；当前没有下列源码/CLI。获得继续开发授权后才实施。

## 1. 每轮工作协议

1. 读当前状态及前置约束，确认唯一写入权。
2. 选择任务板一个 ID，写“要证明什么、哪些文件、最短测试、停止条件”。
3. 获取当前 Git 状态/指纹，不覆盖未知修改；具备授权后建立独立本地版本基线。
4. 先最小反例/诊断，再实现；失败一次查证据，同假设两次无进展换诊断，不刷全量。
5. 输出变更、实测、未测、运行进程及下一步；更新三个当前入口文件。

## 2. P1：风险最高部分先验证

先 ENV 清单，再选择一个引擎候选。建议首先验证人形轻盘动作和输送接驳两个风险点；不先制作大场景或漂亮界面。
四实验均有：初始场景、输入接口、禁止的捷径、完成/失败判据、实际命令、版本、日志、墙钟上限。
先用最小场景验证，随后共同加载所有角色验证时钟、名称与资源余量。
失败须区分模型错误、控制不可达、感知缺失、接触不稳定、算力不足，不能统一叫“参数问题”。
P1-GATE-07 决策要说明首版是否仍可实现；若只能改为固定底座或虚假货物交接，必须停止请求范围决定。

## 3. P2：核心与物理适配分开

建议模块职责（目录名是规划，不是现存代码）：

| 模块 | 负责 | 禁止 |
| --- | --- | --- |
| core/orders | 订单/schema/库存与状态机 | ROS 与仿真直接调用 |
| core/resources | 预约、占用、代次与清空 | 租约过期即判 FREE |
| core/transfers | 双方握手与交接事务 | 收到一个 ACK 即改货物归属 |
| adapters | 设备技能、反馈与取消 | 绕过最终命令门 |
| perception | 带坐标/年龄/不确定性的观测 | 读取评测真值兜底 |
| supervision | 互锁、watchdog、停止策略 | 自报安全即 PASS |
| evaluation | 独立物理/安全判据 | 返回物体真值给控制 |

接口先用 fake 实现测试重复请求、迟到回调、部分成功、掉线与取消。fake 模式显式标记，不能成为正式运行的静默回退。
账本事务保存状态与事件；物理执行无法“数据库回滚”，只能通过新观测对账并停止不确定操作。

## 4. P3：场景与感知导航

步骤：静态世界/坐标 → 一个 AMR 的 scan/odom/TF → SLAM 建图保存 → 地图定位与 Nav2 → 第二台实例 → RGB-D 与点云 → 停靠测量。
每一步先查数据是否真实、新鲜、坐标正确，再调规划参数。不得同时启用建图与定位节点争抢 map→odom。
视觉流程：深度有效性/裁剪 → 滤波 → 桌面分离 → 分离物体提取 → 类别/几何估计 → 坐标转换 → 可达检查。
PCL 的确切 API 和绑定在环境选择后决定；若不用 PCL 而换其他库，必须在能力表明确，不能仍写“已集成 PCL”。
冻结首版范围与测试 manifest，所有随机化有种子和合法范围。

## 5. P4：技能闭环

每技能定义：前置条件、资源、输入观测、执行/重观测时机、完成证据、失败代码、超时、取消后的支撑状态。
人形先空盘，机械臂先单件，输送先空盘后标准满盘。真实相机证据接通后再声明视觉技能完成。
抓取失败先确认接触、可达性与观测误差；不能直接放大吸附力或位置容差。
验收分辨“物体暂时经过目标”与“释放后稳定停留”；保持观察窗口由测量冻结。

## 6. P5/P6：先单链，再竞争

P5 订单链中每次归属变更必须可追溯到一次真实交接。录制完整 episode，不能拼接不同运行片段宣称全链。
P6 加两订单队列和两车资源竞争，检查收货缓冲容量。先保证完成与不串单，再考虑并行效率。
场景中的不同等待点不能互相堵路；“所有机器人停住”不是死锁解决。
故障采用版本化注入，明确时间/条件和预期结果；不能把故障测试失败临时改为成功定义。

## 7. P7：交付，不再无限加需求

冻结配置与资产 → 完整矩阵 → 汇总原始结果 → 独立目录复现 → 使用文档与限制 → 用户决定发布。
未来启动脚本应有自检、显式模式、唯一 run_id、PID 管理、限时及定向停止；现在不创建空脚本假装可运行。
演示至少包括一次完整订单、两车竞争、一次安全拒绝/待处理；视频只是辅助证据，不替代报告。

## 8. 需求追踪

| 用户目标 | 实现门 | 核验 |
| --- | --- | --- |
| 人形参与而非装饰 | P1-H/P4-HUMAN | 自由底座、实际空盘接触、N01 |
| 机械臂备料 | P1-A/P4-ARM | 数量/类型与释放后位置、N01/N06/F01 |
| 传送带真实交接 | P1-C/P4-BELT | 支撑/互锁、N07/F04–F06 |
| SLAM/Nav2 | P3-NAV | 建图记录、定位导航与 N02/N05/F07 |
| 点云/PCL | P3-VISION | 版本/处理输出/定位误差、N06/F02 |
| 多机器人协作 | P6 | N03–N05、资源/归属完整性 |
| 随时换 AI | P0及每轮 | 三个当前文件、版本与证据、唯一写入权 |

建图与点云校准报告是矩阵外的必需前置证据，不能只用配送成功替代。
