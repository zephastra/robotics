## 项目定位

**009：多机器人任务协同、交通预约与故障接管仿真系统。**

先做同一 Gazebo 世界里的两台四轮差速机器人，再验证三台。真正的新能力是：谁接哪个任务、谁先过窄道、谁等在哪里、掉线后谁接手，以及系统如何证明没有撞车、重复执行或伪造完成。

不是两台机器人同步播放轨迹；不是先复制多个人形模型；不依赖 007/008 完成。以后可通过适配器接入人形机器人，但第一版没有人形物理验证，也没有实物装卸。

## 给用户的阶段检查方法

- P1：查看任务分配、去重、资源互斥与掉线测试，不需要看机器人画面。
- P2/P3：单车能可靠导航，再检查双车话题、TF 和控制是否串线。
- P4：两车迎面请求窄道，必须一车等待、一车通过，随后交换；不能通过等待几秒的固定脚本冒充调度。
- P5：三车任务、低电、掉线、接管和不可接管情况。
- P6/P7：展示真实状态，冻结批测，独立路径复现，最后才能讨论发布。

主线不承诺“所有故障都能自动完成”。机器人坏在唯一通道内时，另一台安全等待并报告需清障，比穿过去或假装任务完成更正确。
